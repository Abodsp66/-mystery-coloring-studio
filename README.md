# انسياب — Flow Studio 1.0

أداة جديدة مستقلة لتحويل الرسوم الملونة إلى أوراق تلوين غامضة، بمحرك JavaScript داخل Web Worker. تعمل الملفات محليًا بالكامل، دون Python أو Pyodide أو تنزيل مكتبات هندسة عند التحويل. الموقع الجديد في **`flow-studio/`**؛ بقيت النسخة الأصلية في `dist/` وأرشيفها ومراجع PDF محفوظة.

التمويه يجمع خطوطًا ممتدة بانحناء عبر المشهد، وامتدادات مستمدة من تقدير مماسات وتقوس حدود الصورة. تُبنى شبكة حدود مشتركة للحل واللغز. لا تُتاح الطباعة مع خلية غير مرقمة؛ يُبسّط التفصيل الصغير ضمن حد معلن، أو تُرفض النتيجة للمراجعة.

```sh
sh scripts/serve-flow.sh
```

يعمل خادم التطوير على المنفذ **8765**. استخدم معاينة المنفذ السحابية إن توفرت؛ لا تفتح الصفحة باستخدام `file://`.

- [دليل الأداة الجديدة، المنهج، الاختبارات وحدود النتيجة](docs/FLOW_STUDIO_AR.md)
- [توثيق تطوير النسخة السابقة](DEVELOPMENT_AR.md)
- [توثيق النسخة الأصلية وتشغيل Windows](README_AR.md)
- [تعليمات العمل على المستودع](AGENTS.md)

على Windows افتح `flow-studio/START-WINDOWS.cmd`. للنشر على استضافة ثابتة، انشر **محتويات `flow-studio/`** بما فيها ملفات `.mjs` والخط و`vendor/`، وليس `dist/`. لا توجد خطوة npm/build. لا تفتح `index.html` بالنقر المزدوج.

التحقق:

```sh
sh scripts/check-flow.sh
node --test --test-isolation=none tests/flow_engine.test.mjs
python3 tests/flow_browser.py --url http://127.0.0.1:8765/
```

يتطلب اختبار المتصفح أدوات `requirements-dev.txt` وChromium؛ التشغيل نفسه لا يحتاجها. لتجهيز ZIP مستقل: `python3 scripts/package_flow_studio.py`.
