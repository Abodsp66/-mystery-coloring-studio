# Mystery Coloring Studio V5.2.1

تطبيق عربي لتحويل الصور إلى رسومات تلوين مرقمة، مع معالجة داخل المتصفح باستخدام Pyodide.

ملفات المشروع الأصلي مفكوكة في `dist/`، مع الاحتفاظ بملف ZIP والمرجع الرسومي الأصلي.

```sh
sh scripts/serve.sh
```

يعمل خادم التطوير على المنفذ **8765**. استخدم معاينة المنفذ السحابية إن توفرت؛ لا تفتح الصفحة باستخدام `file://`.

- [دليل التطوير والتشغيل والاختبارات](DEVELOPMENT_AR.md)
- [توثيق النسخة الأصلية وتشغيل Windows](README_AR.md)
- [تعليمات العمل على المستودع](AGENTS.md)

لا يحتاج تقديم الموقع إلى تثبيت حزم. يحتاج أول تحويل إلى اتصال بـ `cdn.jsdelivr.net` لتنزيل Pyodide ومكتبات الهندسة.
