# Mystery Coloring Studio V6 — استوديو الطباعة

تطبيق عربي لتحويل الصور إلى رسومات تلوين مرقمة، بمعالجة داخل المتصفح باستخدام Pyodide. تضيف V6 تقسيمًا بوحدات الطباعة، وفحص اتساع الرموز، ولوحة أقلام اختيارية، وتصدير PDF متجهي بخط مضمّن.

ملفات المشروع الأصلي مفكوكة في `dist/`، مع الاحتفاظ بملف ZIP والمرجع الرسومي الأصلي.

```sh
sh scripts/serve.sh
```

يعمل خادم التطوير على المنفذ **8765**. استخدم معاينة المنفذ السحابية إن توفرت؛ لا تفتح الصفحة باستخدام `file://`.

- [دليل التطوير والتشغيل والاختبارات](DEVELOPMENT_AR.md)
- [توثيق النسخة الأصلية وتشغيل Windows](README_AR.md)
- [تعليمات العمل على المستودع](AGENTS.md)

لا يحتاج تقديم الموقع إلى تثبيت حزم. يحتاج أول تحويل إلى اتصال بـ `cdn.jsdelivr.net` لتنزيل Pyodide ومكتبات الهندسة.

ابدأ بصورة واحدة مقصوصة إلى إطار الرسم، و12 أو 18 لونًا وA4. قارن الحل بالأصل، وراجع الخلايا غير المرقمة قبل تنزيل PDF. نجاح الفحص الهندسي لا يقيس صعوبة التعرف إلى المشهد أو مطابقة الأقلام على الورق.
