# Original benchmark illustrations

The attic and courtyard SVGs were authored from scratch for this project and
are released under CC0-1.0. They contain no reference-book artwork or characters.

They exercise flat colors, curves, holes, adjacent regions, narrow details,
A4 label fit, and the distinction between a printable result and a review draft.
The benchmark rasterizes at an exact 512×672 canvas to avoid a fractional white
overscan column. Expected source colors and graphics remain in these SVG files;
results are generated under the ignored `test-results/` directory.
